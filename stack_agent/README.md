- https://www.kaggle.com/datasets/stackoverflow/stacksample/data
- https://docs.bauplanlabs.com/examples/rag

Divide text into chunks, compute embeddings of each chunk, and store them in a local vector DB for retrival and RAG.

chunks_all -> complete data, chunk size = 500, chunk overlap = 50
chunks_sample -> sample data 50000, chunk size = 1000, chunk overlap = 100
